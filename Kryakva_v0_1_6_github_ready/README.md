# Kryakva 🦆 (Windows)

Desktop-pet ассистент: утка на рабочем столе + ПКМ-меню с подменю + голос (Vosk) + опционально локальная нейросеть (Ollama/Gemma).

## Запуск
1) `install.bat`
2) `run.bat`
3) ПКМ по утке → Голос ▶ → Выбрать Vosk-модель…

## Нейросеть (локально)
- Установи Ollama: https://ollama.com/
- `ollama pull gemma2:2b`
- ПКМ → Мозг ▶ → включить
